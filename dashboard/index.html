How the pipeline works

1. Ingest100,000 reviews, fixed sample
2. Queue + cacheSQLite, one task per unique text
3. Enrich · Jevparallel workers, batch 5
4. Verify · Jevblind 10% sample
5. Group · Jevcomplaints → issues
6. Rank · codepriority = severity sum
7. Memo · Haiku 5.5aggregates only, validated

A Python orchestrator controls the stages, spending caps and stop conditions (orchestration, not a swarm). Green stages call a model; the rest is deterministic code.
